2. Tệp / Package THỪA & TRÙNG LẶP

CRITICAL packages/swift ↔ packages/swift-core — Nội dung gần giống nhau hoàn toàn
  • packages/swift → tên NPM: @wikialisa/swift-sdk-internal, v1.0.1 — dùng fast-xml-parser, ioredis, uuid, zod. README: "do not import directly"
  • packages/swift-core → tên NPM: @wikialisa/swift-core, v1.0.0 — cùng dependencies hệt nhau
  • Kết luận: packages/swift là phiên bản cũ/gốc của swift-core. Nên xóa packages/swift.
CRITICAL packages/swift-adapter ↔ packages/sdk-internal — Cả hai đều DEPRECATED
  • packages/swift-adapter v1.0.1: DEPRECATED, dùng swift-core thay thế
  • packages/sdk-internal v1.0.1: DEPRECATED, re-exports từ swift-adapter, cộng thêm utils nội bộ
  • Vấn đề: 8/11 apps vẫn import @wikialisa/sdk-internal. services/swift-chain-bridge và services/swift-gateway vẫn import @wikialisa/swift-adapter trực tiếp
  • Kết luận: Cả hai cần migrate sang @wikialisa/swift-core trước khi xóa
HIGH packages/swift-gateway ↔ services/swift-gateway — Trùng tên miền
  • packages/swift-gateway → NPM package: @wikialisa/swift-gateway (thư viện)
  • services/swift-gateway → service chạy: @wikialisa/swift-gateway (runtime), nhưng tên NPM giống hệt!
  • Vấn đề: Conflict tên package trong workspace. services/swift-gateway nên đổi tên thành @wikialisa/svc-swift-gateway
MEDIUM temp-wikialisa-ui/ — Thư mục tạm không nên trong workspace
  • Chứa HeroUI template gốc (laravel-template, next-app-template, react-router-template, v.v.)
  • Có package.json riêng với workspace packages/core/* — không thuộc pnpm-workspace.yaml của root
  • Không được tham chiếu bởi bất kỳ app hay service nào
  • Kết luận: Xóa hoặc chuyển ra ngoài workspace. Đây là artifact từ quá trình clone/transform HeroUI
MEDIUM axvn.vn.txt, axvn.zip — File không liên quan
  • Hai file này nằm ở root workspace, không có tham chiếu nào trong code
  • Kết luận: Thừa, xóa đi hoặc chuyển vào docs/

4. Tệp / Cấu Hình THIẾU

CRITICAL Thiếu tsconfig.base.json ở root — turbo.json khai báo globalDependencies
  • turbo.json khai báo globalDependencies: ["tsconfig.json", "tsconfig.base.json"]
  • Root workspace không có tsconfig.json hoặc tsconfig.base.json
  • Mỗi app/package tự có tsconfig riêng — không có shared base config
  • Kết luận: Tạo /tsconfig.base.json root với strict settings dùng chung
CRITICAL Thiếu .gitignore ở workspace root (chỉ có .gitignore nhưng cần kiểm tra)
  • File .gitignore tồn tại nhưng cần đảm bảo exclude: *.tgz (hiện có swift-adapter-1.0.0.tgz trong repo)
  • packages/swift-adapter/vnkrvietnam-swift-adapter-1.0.0.tgz — file binary trong git là sai
HIGH Thiếu .env file — apps không có .env.local mẫu riêng
  • Chỉ có .env.example ở root, không có hướng dẫn tạo .env cho từng app/service
  • turbo.json khai báo globalDependencies: [".env", ".env.*"] nhưng không có file .env thực tế
HIGH Thiếu eslint config dùng chung (ESLint 9.x flat config)
  • Root package.json dùng @typescript-eslint v8 + eslint v9 (flat config)
  • Các apps dùng eslint-config-next v14 (legacy .eslintrc format)
  • Không có eslint.config.js ở root — không có rule thống nhất cho toàn workspace
HIGH Thiếu .npmrc ở root
  • Packages như @wikialisa/web3-config, @wikialisa/swift-core khai báo publishConfig với GitHub registry
  • Không có .npmrc để cấu hình @wikialisa:registry → GitHub Packages authentication
  • Sẽ fail khi pnpm install trên môi trường CI
MEDIUM Thiếu vitest.config ở root hoặc shared test setup
  • Root package.json cài vitest nhưng chỉ packages/swift và packages/swift-adapter có vitest.config.ts
  • services/* không có bất kỳ test file nào được tham chiếu
MEDIUM Thiếu Dockerfile cho services/swift-chain-bridge, services/role-engine
  • Các services có Dockerfile: fiat-connector-api, indexer-subgraph, mock-mgw, dune-alert-bots, otc-liquidity-engine
  • Thiếu Dockerfile: swift-chain-bridge, role-engine, api-gateway
  • docker-compose sẽ không thể build các service này
MEDIUM apps/digital-twin-engine — Không có Dockerfile, không trong PM2 ecosystem
  • Là Node app (không phải Next.js) nhưng không có Dockerfile và không được đăng ký trong ecosystem.config.cjs
  • Không rõ cách deploy: PM2, Docker, hay systemd
